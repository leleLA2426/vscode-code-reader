# Code Reader v0.3.1 - Design Spec

> Date: 2026-07-27 | Status: In Progress | Follows v0.3.0

## 1. Overview

v0.3.1 implements cross-file symbol indexing for go-to-definition, find-references, and call graph. New C++ indexer module, plus M2/M3 bug fixes.

## 2. Scope

| Item | Status |
|------|--------|
| M2: Multi-panel | ✅ Fixed |
| M3: Multi-root workspace | ✅ Fixed |
| M5: Content Security Policy | ❌ Not started |
| Go to Definition | ❌ Needs C++ indexer |
| Find References | ❌ Needs C++ indexer |
| Call Graph | ❌ Needs C++ indexer |

## 3. New Architecture

```
C++ indexer (new)
  projectIndexer: recursive scan -> Parser::parse() for each file
  symbolIndex:    symbolName -> [{file, line, kind}]
  callGraph:      [{caller, callee, file, line}]

TS layer
  nativeBridge: scanProject/findDefinition/findReferences/getCallGraph
  extension.ts:  goToDefinition/findReferences/showCallGraph commands
  readerPanel.ts: M2 Map<filePath, Panel> multi-panel
```

## 4. Key Decisions

- Indexing: on-demand full scan on first use of jump/find
- Languages: TS/TSX/Python/C/C++
- Call graph max nodes: 200
