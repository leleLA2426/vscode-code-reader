# Code Reader v0.3.1 — 设计规约

> 日期: 2026-07-27 | 状态: 进行中 | 上接 v0.3.0

## 1. 概述

v0.3.1 实现跨文件符号索引，支持定义跳转、引用查找和调用关系图。新增 C++ 索引引擎，修复 M2/M3。

## 2. 范围

| 内容 | 状态 |
|------|------|
| M2: 多面板管理 | 已修复 |
| M3: 多根工作区 | 已修复 |
| M5: Content Security Policy | 未开始 |
| 定义跳转 | 需 C++ 索引 |
| 引用查找 | 需 C++ 索引 |
| 调用关系图 | 需 C++ 索引 |

## 3. 架构新增

```
C++ indexer (新增)
  projectIndexer: 递归扫描项目，每个文件调用 Parser::parse()
  symbolIndex:    符号名映射到定义和引用位置列表
  callGraph:      调用者和被调用者关系边

TS 层
  nativeBridge: scanProject/findDefinition/findReferences/getCallGraph
  extension.ts:  goToDefinition/findReferences/showCallGraph 命令
  readerPanel.ts: M2 Map<filePath, Panel> 多面板管理
```

## 4. 关键决策

- 索引策略：用户首次使用跳转/查找时按需全量扫描
- 支持语言：TS/TSX/Python/C/C++
- 调用图最大节点数：200
